# Local Development

## Start the frontend

```bash
cd web
bun install
bun run dev
```

Open `http://localhost:3000`. Vite does not include Relay, so default same-origin model requests reach the frontend server and local mode is interface-only by default.

To test generation, configure a same-origin reverse proxy in a controlled environment or explicitly use a CORS-enabled test Relay. Never place provider credentials in frontend source or build variables.

## Start the documentation

```bash
cd docs
bun install
bun run dev
```

Common locations:

- Canvas and pages: `web/`
- Same-origin model requests: `web/src/services/api/`
- Production routing and R2: `deploy/worldcodes/`
- Documentation: `docs/content/docs/`
