# 本地开发

## 启动前端

```bash
cd web
bun install
bun run dev
```

打开 `http://localhost:3000`。Vite 不包含 Relay，默认同源模型请求会落到本地前端服务器，因此本地模式默认只用于界面开发。

如需验证生成流程，应在受控环境为本地域名配置同源反向代理，或显式使用允许跨域的测试 Relay。不要把供应商密钥写进前端源码或构建变量。

## 启动文档站

```bash
cd docs
bun install
bun run dev
```

常用目录：

- 画布与页面：`web/`
- 同源模型请求：`web/src/services/api/`
- WorldCodes 生产路由与 R2：`deploy/worldcodes/`
- 文档内容：`docs/content/docs/`
