# 功能介绍

## 画布与节点

- 创建、重命名、导入、导出和删除多个画布项目。
- 拖拽、缩放、框选、连线、小地图、撤销重做与快捷键。
- 文本、图片、视频、音频、生成配置和分组节点。
- 将提示词与参考素材连接为可继续编辑的生成流程。
- 下载生成结果，或保存到浏览器内的“我的素材”。

画布项目、素材和生成记录默认保存在当前浏览器的 IndexedDB。清理站点数据会删除这些本地内容。

## WorldCodes Relay 模型

生产站默认只调用同源 WorldCodes Relay，不直接连接上游模型供应商：

- Grok Imagine：图片生成。
- GPT Image 2：文生图、参考图与编辑。
- Nano Banana 2：文生图与参考图生成。
- MiniMax H3：视频生成，支持图片、视频和音频参考。
- 文本与语音模型：分别使用同源 Responses 与 Speech 接口。

浏览器保存并发送用户自己的 WorldCodes API Key；供应商密钥、模型路由和计费映射只保留在 Relay。生产 CSP 不允许浏览器绕过 Relay 连接任意模型地址。

## 参考素材与 R2

- 编辑期间，本地图片、音频和视频只保存在浏览器。
- 生成接口接受公网素材时直接使用其地址。
- MiniMax H3 需要公网可读参考素材时，Relay 签发短时上传地址，浏览器把文件直接上传到 R2 临时对象，PixStag 通过短读取域名访问。
- Relay 只接收上传 ID，不接收媒体文件字节。
- 任务结束后主动清理对象；异常任务由 R2 生命周期兜底过期。

## 提示词与插件

提示词库支持搜索、筛选、查看详情、复制和加入素材。WorldCodes 生产版预置 7 组经过审核的只读 JSON 数据源，结果缓存在浏览器 IndexedDB；页面不提供外部仓库跳转，生产 CSP 只放行固定的数据域名。

画布保留内置与本地节点插件能力。生产版不执行远程下载的插件 JavaScript，避免其读取同源页面数据和凭据。

## 配置与同步

- 配置文件可导入和导出；导出内容可能包含凭据，请勿公开分享。
- 生产站的模型流量固定走同源 Relay。
- WebDAV 与任意外部 Base URL 仅作为自托管兼容能力保留；WorldCodes 生产 CSP 默认不放行这些外部地址。

## 本地 Agent

Agent 是可选的本地桥接器，需要访问用户电脑上的 Codex、Skills 与工作区，不能作为 Relay 共享服务运行。WorldCodes 自有安装包发布前，主站默认隐藏 Agent，图片和视频生成不受影响。

详情见 [本地 Agent](/zh-CN/docs/overview/codex-app-plugin)。

## 当前限制

- 浏览器本地数据不会自动跨设备同步。
- 本地静态预览不包含 Relay；需要生成能力时必须配置同源反向代理，或在自托管环境显式配置允许的接口。
- 画布以桌面端体验为主，移动端触控仍需继续优化。

## 上游 0.18 同步

新增分组与解散组、树形节点列表、参考内容栏、视频截帧和多文本备选；图片分辨率与比例分别设置。视频专用渠道仍按已验证模型档位限制参数。可选本地代理默认关闭，运行 WorldCodes 自托管代理后可转发外部模型和 WebDAV 请求。图片领取复用原结果，视频刷新后恢复原任务。
