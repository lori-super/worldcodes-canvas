# Docker 部署

## 构建静态前端

```bash
cd /path/to/worldcodes-canvas
docker compose up -d --build
```

该命令只使用当前源码构建 `worldcodes-canvas` 容器，不拉取其他项目的预构建镜像。默认访问 `http://localhost:3000`。

也可以直接构建：

```bash
docker build -t worldcodes-canvas:local .
docker run --rm -p 3000:3000 worldcodes-canvas:local
```

## 重要边界

根目录镜像只包含 Vite 静态前端，不包含 WorldCodes Relay。它适合界面预览；完整生产生成能力还需要：

- 同域 Caddy 将允许的 `/v1/*` 与 `/v1beta/*` 路由转发给 Relay。
- Relay 配置 MiniMax H3、图片模型和用户鉴权。
- Relay 配置 R2 临时素材桶、短读取域与清理策略。

生产安装合同位于 `deploy/worldcodes/`。不要在静态容器里放供应商 API Key。

## 数据

画布、素材、生成记录和提示词缓存保存在浏览器 IndexedDB，静态容器不需要持久化数据卷。生产版提示词库只访问固定的只读 JSON 数据源；用户上传的参考媒体只在生成需要时直传 R2 临时对象。

## 独立文档站

```bash
cd docs
docker compose up -d --build
```

文档站是单独的 Next.js 服务，不包含模型 Relay。
