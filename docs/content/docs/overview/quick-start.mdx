# Quick Start

## Local preview

```bash
cd /path/to/worldcodes-canvas/web
bun install
bun run dev
```

Open `http://localhost:3000`. Vite provides the interface only; it does not include the same-origin Relay, so default model generation does not work without an additional reverse proxy.

## Production deployment

WorldCodes production has three parts:

1. Static Canvas files at `canvas.worldcodes.online`.
2. Same-origin `/v1/*` and `/v1beta/*` routes reverse-proxied by Caddy to WorldCodes Relay.
3. Private temporary R2 objects uploaded directly by the browser when MiniMax H3 needs public reference media.

The audited Caddy routes, R2 configuration, release scripts, and verification contracts are in `deploy/worldcodes/`. A static-only Vercel or Render deployment is not a complete production setup because it has no same-origin Relay.

## First use

1. Add the user's WorldCodes API key to the WorldCodes Relay channel in Settings.
2. Open the image, video, or canvas workspace and select a grouped model.
3. Local references remain in this browser and use temporary R2 upload only when H3 needs public access.

Production includes seven audited read-only prompt JSON sources shipped with the site and provides no external repository navigation. External WebDAV and arbitrary model Base URLs remain disabled. Self-hosters adding other origins must update CSP and security policy.
