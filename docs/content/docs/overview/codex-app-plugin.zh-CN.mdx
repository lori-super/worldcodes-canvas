# 本地 Agent

WorldCodes Canvas Agent 是可选的本地桥接器，用来让 Codex 读取和操作当前画布。图片生成、视频生成、参考素材和 R2 临时上传都不依赖 Agent。

## 为什么不能放在 Relay

Agent 需要访问用户电脑上的 Codex 登录状态、Skills、工作区和本地文件。把它作为多人共享服务放到 Relay 会失去这些本机能力，也会带来账号与文件隔离风险。因此：

- Canvas Web 与 Relay 可以部署在服务器。
- Agent 只能运行在每位用户自己的电脑。
- 网页仅通过 localhost 与该用户的 Agent 通信。

## 当前状态

主站已显示 Agent 入口，仓库也已提供 WorldCodes 自有插件、MCP 配置和 Agent 源码；其中不再引用或启动上游插件、Agent 包和站点。正式安装包固定从 WorldCodes Canvas 自有站点下载。

启动本地 Agent：

```bash
npx -y https://canvas.worldcodes.online/downloads/worldcodes-canvas-agent-0.6.0.tgz
```

如需内部开发，可从本地源码构建 Agent：

```bash
cd /absolute/path/to/worldcodes-canvas/canvas-agent
npm install
npm run build
node dist/index.js
```

MCP ID `infinite-canvas` 与本地目录 `~/.infinite-canvas` 暂时作为兼容标识保留，避免已有用户配置和数据失效；它们不会显示为站点品牌。
