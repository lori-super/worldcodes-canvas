# Features

## Canvas and nodes

- Create, rename, import, export, and delete canvas projects.
- Pan, zoom, select, connect, use the minimap, undo and redo.
- Work with text, image, video, audio, generation, and group nodes.
- Connect prompts and references into editable generation workflows.
- Download results or save them to the browser-based asset library.

Projects, assets, and generation history are stored in this browser's IndexedDB. Clearing site data removes them.

## WorldCodes Relay models

Production calls only the same-origin WorldCodes Relay:

- Grok Imagine, GPT Image 2, and Nano Banana 2 for images.
- MiniMax H3 for video with image, video, and audio references.
- Same-origin Responses and Speech endpoints for text and audio.

The browser stores and sends the user's WorldCodes API key. Provider credentials, routing, and billing mappings remain inside Relay. Production CSP prevents the browser from bypassing Relay to contact arbitrary model providers.

## References and R2

- Local reference media remains in browser storage while editing.
- Public references can be submitted directly.
- When MiniMax H3 needs public access, Relay issues a short-lived upload URL and the browser uploads bytes directly to private temporary R2 storage.
- Relay receives only the upload ID, never the media bytes.
- Terminal jobs clean up objects; an R2 lifecycle rule handles abandoned jobs.

## Prompts and plugins

The prompt library supports search, filters, details, copy, and asset import. WorldCodes production includes seven audited read-only JSON sources cached in browser IndexedDB. The UI provides no external repository navigation, and production CSP allows only the fixed data origin.

Built-in and local node plugins remain available. Production does not execute remotely downloaded plugin JavaScript.

## Configuration and synchronization

- Settings can be imported and exported; exported credentials must not be shared.
- Production model traffic is fixed to the same-origin Relay.
- WebDAV and arbitrary external Base URLs remain self-hosting compatibility options, but WorldCodes production CSP does not allow those external origins.

## Local Agent

The optional Agent needs each user's local Codex, Skills, and workspace and therefore cannot run as a shared Relay service. It remains hidden until a WorldCodes-owned package is released; core generation does not depend on it.

See [Local Agent](/docs/overview/codex-app-plugin).

## Current limitations

- Browser data is not synchronized across devices automatically.
- A static local preview does not include Relay; generation requires a same-origin reverse proxy or an explicitly allowed self-hosted endpoint.
- The canvas is optimized for desktop use.
