# Codex App Plugin and Local Agent

WorldCodes Canvas provides its own Codex plugin and local Agent. After installation, ask Codex to “Open WorldCodes Canvas” to open the site, read and create nodes, connect workflows, and start generation.

Image/video generation, reference media, and temporary R2 uploads do not require the Agent.

## Option 1: Install the WorldCodes Codex plugin

```bash
codex plugin marketplace add lori-super/worldcodes-canvas
codex plugin add worldcodes-canvas@worldcodes-canvas
```

Start a new Codex task after installation and enter:

```text
Open WorldCodes Canvas
```

The plugin loads the WorldCodes Canvas MCP. Its `open-canvas` Skill starts the self-hosted WorldCodes Agent, reads the Local URL and Connect token, opens `https://canvas.worldcodes.online/`, and connects automatically.

## Option 2: Run the Agent directly

For web-side chat without loading Canvas MCP tools into a Codex task, run:

```bash
npx -y https://canvas.worldcodes.online/downloads/worldcodes-canvas-agent-0.6.1.tgz
```

The Agent prints a Local URL and Connect token. The site normally discovers them automatically; enter them manually in the Agent panel only if discovery fails.

## MCP versus the web Agent

- The plugin's MCP process provides canvas tools to Codex.
- The regular Agent process provides the local web connection and sidebar chat.
- Both read the same local connection settings but have different responsibilities.
- Running the regular Agent alone does not install MCP or add tools to the Codex context.

The compatibility MCP ID `infinite-canvas` and local directory `~/.infinite-canvas` remain temporarily for existing users. The plugin, Agent package, service name, repository, and site are all provided by WorldCodes.

## Security boundary

The Agent needs access to the user's local Codex login, Skills, workspace, and files, so it runs only on the user's computer. It binds to `127.0.0.1`, authenticates the site with a token, and locks allowed Origins. Relay never stores or runs local workspaces.

## Update and removal

Reinstall the plugin after changing its manifest, MCP configuration, or Skills, then start a new Codex task.

```bash
codex plugin remove worldcodes-canvas@worldcodes-canvas
codex mcp remove infinite-canvas
```

## Local development

```bash
cd /absolute/path/to/worldcodes-canvas/canvas-agent
npm install
npm run build
node dist/index.js --debug
```
