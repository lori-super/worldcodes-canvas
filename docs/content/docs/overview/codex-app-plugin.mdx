# Local Agent

WorldCodes Canvas Agent is an optional local bridge that lets Codex read and operate the active canvas. Image generation, video generation, reference assets, and temporary R2 uploads do not depend on it.

## Why it does not run on Relay

The Agent needs the user's local Codex login, Skills, workspace, and files. A shared Relay deployment cannot provide those capabilities safely. Canvas Web and Relay run on the server, while each Agent user runs a private local process connected through localhost.

## Current status

The WorldCodes Agent package and Codex plugin have not been released. The main site hides the Agent entry, and plugin distribution plus automatic MCP startup remain disabled to prevent accidental third-party installation.

Internal developers can build the Agent from local source:

```bash
cd /absolute/path/to/worldcodes-canvas/canvas-agent
npm install
npm run build
node dist/index.js
```

The MCP ID `infinite-canvas` and local directory `~/.infinite-canvas` remain compatibility identifiers so existing local settings and data continue to work; neither is presented as the product brand.

## Requirements before release

1. Publish `@worldcodes/canvas-agent`.
2. Publish the WorldCodes Codex plugin with the WorldCodes site configured.
3. Complete signing, version updates, and installation guidance.
4. Set `VITE_AGENT_ENABLED=true` in the Web build environment.
