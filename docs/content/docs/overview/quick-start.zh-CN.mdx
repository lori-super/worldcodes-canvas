# 快速开始

## 本地预览

```bash
cd /path/to/worldcodes-canvas/web
bun install
bun run dev
```

打开 `http://localhost:3000`。本地 Vite 只提供界面预览，不包含同源 Relay；在没有额外反向代理时，默认模型生成接口不会工作。

## 生产部署

WorldCodes 生产结构由三部分组成：

1. Canvas 静态站点部署到 `canvas.worldcodes.online`。
2. 同域 `/v1/*` 与 `/v1beta/*` 由 Caddy 反向代理到 WorldCodes Relay。
3. MiniMax H3 的本地参考素材由浏览器直传私有 R2 临时对象。

部署合同、Caddy 路由、R2 配置和发布校验位于仓库的 `deploy/worldcodes/`。不要只把静态前端发布到 Vercel 或 Render 后当作完整生产站；那样没有同源 Relay，默认生成能力不可用。

## 首次使用

1. 打开配置页，在 WorldCodes Relay 渠道填入用户自己的 WorldCodes API Key。
2. 进入图片、视频或画布工作台，选择已经分组的模型。
3. 本地参考图片、视频和音频会保存在当前浏览器；需要 H3 公网读取时自动走 R2 临时上传。

生产版预置 7 组经过审核的只读提示词 JSON 数据源，但不提供外部仓库跳转，也不启用外部 WebDAV 或任意模型 Base URL。自托管者若要增加其他来源，需要同步调整 CSP 与安全策略。
