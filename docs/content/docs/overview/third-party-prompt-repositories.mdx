# Prompt Sources

Prompt sources are managed from WorldCodes Canvas Settings. WorldCodes production includes seven audited read-only JSON sources cached in browser IndexedDB. The site provides no links to external repositories.

Production CSP allows only the fixed built-in data origin. Self-hosters adding another source must verify its license, safety, and availability and update their own CSP; WorldCodes production does not allow arbitrary origins.
